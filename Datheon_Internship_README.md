## 📌 About the Internship

This repository brings together the work completed as part of my **Machine Learning & Data Science internship with Datheon**.

The internship provided an opportunity to apply machine learning concepts to practical datasets, work through end-to-end modelling workflows, and compare algorithms for different problem types.

The repository contains four projects:

1. Iris Classification Benchmark
2. Real Estate Housing Price Prediction
3. NLP Sentiment Classification
4. Customer Churn Prediction

Each project demonstrates relevant stages such as data exploration, preprocessing, model training, evaluation, and interpretation.

---

## 🗂️ Projects

### 1. 🌸 Iris Classification Benchmark

**Problem type:** Classification

Classifies iris flowers into their respective species using machine learning algorithms.

**Work carried out**
- Explored and prepared the iris dataset.
- Trained classification models.
- Compared Logistic Regression and Decision Tree.
- Evaluated model performance and examined decision boundaries.

**Algorithms:** Logistic Regression, Decision Tree

---

### 2. 🏡 Real Estate Housing Price Prediction

**Problem type:** Regression

Predicts housing prices using available property-related features.

**Work carried out**
- Explored and prepared the housing dataset.
- Built regression models for price prediction.
- Compared baseline and regularized regression approaches.
- Studied regularization and its role in model generalization.

**Algorithms:** Linear Regression, Ridge Regression, Lasso Regression

---

### 3. 💬 NLP Sentiment Classification

**Problem type:** Natural Language Processing / Classification

Classifies text reviews as **positive (1)** or **negative (0)** using text-processing techniques and traditional machine learning.

**Work carried out**
- Cleaned and preprocessed review text.
- Applied tokenization, stop-word removal, and lemmatization.
- Converted text into numerical features using TF-IDF.
- Compared Multinomial Naive Bayes and Logistic Regression.

**Algorithms and techniques:** TF-IDF, Multinomial Naive Bayes, Logistic Regression, text preprocessing

> **Dataset note:** The supplied dataset contains 10 original records. One record has a missing sentiment label, leaving 9 usable records (5 positive and 4 negative). Results from this small dataset should be treated as a workflow exercise, not as evidence of production-level performance.

---

### 4. 📊 Customer Churn Prediction

**Problem type:** Classification

Predicts whether a customer is likely to leave a service using customer-related information.

**Work carried out**
- Explored and prepared the customer churn dataset.
- Built a preprocessing and modelling workflow.
- Addressed class imbalance during model training.
- Evaluated model performance and examined feature importance.

**Algorithms and techniques:** Random Forest, XGBoost, class balancing, feature importance

## 🔄 Typical Project Workflow

The projects follow a practical machine learning workflow, adapted to each dataset:

1. **Data understanding** — inspect the dataset, columns, data types, and target variable.
2. **Exploratory data analysis** — examine distributions, patterns, and relationships.
3. **Data preprocessing** — handle missing values and prepare features.
4. **Feature engineering** — transform data into a format suitable for modelling.
5. **Model development** — train algorithms suited to the task.
6. **Evaluation** — assess performance using relevant metrics.
7. **Comparison and interpretation** — compare approaches and understand model behaviour.
